# صندوق باور — پروتوتایپ سایت

نسخه‌ی نمایشی سایت صندوق باور، بر پایه‌ی طرح کاغذی (`docs/`) و فیگمای صندوق.
سایت کاملاً ایستاست (HTML/CSS/JS بدون فریم‌ورک) و با یک اسکریپت پایتون ساخته می‌شود.

- نشانی نهایی: https://mohammadaghaei.ir
- نشانی github.io فقط به دامنه ریدایرکت می‌کند و محتوا را جداگانه نشان نمی‌دهد.

## ساخت و اجرا

```bash
python3 build.py            # خروجی در dist/
python3 build.py --serve    # ساخت + سرور محلی روی http://127.0.0.1:8797
```

به هیچ پکیجی نیاز نیست (فقط پایتون ۳).

## ساختار

| مسیر | کاربرد |
|---|---|
| `content.py` | همه‌ی متن‌ها، آمار، محورها، پرتفولیو، روایت‌ها، اخبار |
| `build.py` | قالب صفحه‌ها و ساخت خروجی |
| `src/assets/css/site.css` | استایل (توکن‌های رنگ و فونت بالای فایل) |
| `src/assets/js/site.js` | اسلایدر، شمارنده‌ها، فیلترها، پنجره‌ها، فرم چندمرحله‌ای |
| `src/assets/img/` | تصاویر (منبع و مجوز هر تصویر در `CREDITS.json`) |
| `src/assets/brand/` | لوگو (برگرفته از فیگما؛ نسخه‌ی SVG اصلی جایگزین شود) |
| `docs/` | طرح کاغذی |

## پیش از انتشار عمومی

همه‌ی موارد زیر نمونه هستند و باید با اطلاعات واقعی جایگزین شوند:

- آمار (۴۵۰+ / ۲۸ / ۱۶)، زمان‌بندی مراحل پذیرش، تاریخ‌های فراخوان و ضربان
- نام شرکت‌های پرتفولیو، روایت‌ها و نام بنیان‌گذاران (از فیگما یا ساختگی)
- اخبار و مقاله‌ها
- نشانی، تلفن، کد پستی و ایمیل (از فیگما)
- لوگوی بنیاد و دانشگاه (فعلاً نشانه‌ی موقت)
- فرم‌ها به جایی ارسال نمی‌شوند

سایت عمداً `noindex` است و `robots.txt` همه‌چیز را می‌بندد؛ هنگام انتشار واقعی برداشته شود.
